## ⚠️ Репозиторий на 30% будет сломан в каких-то случаях.

zapret2 показался интересным инструментом, так что с большей вероятностью стратегии могут быть нестабильны, поскольку я с ним почти впервые o_O 

единственная особенность - это подхват фейков через папку `bin/`, которая выполнена через `blobs.lua`. ручной запуск выводит все в одну строку (а лимит для batch файла на одну строку 8191 символ), и если запрет спрятан глубоко, то при запуске указывается полный путь до фейка (например, `C:\example\example2\tls_clienthello_example.bin`), из-за чего символов набирается слишком много и стратегия вылетает.

^^ через `service.bat` - `1. install service` такого не возникает.
